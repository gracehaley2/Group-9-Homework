Task 1: Conceptual Questions

  1. If the working directory is myfolder/homework/, the relative path needed to access myfolder/MyData.csv is ../MyData.csv. The .. moves up one directory from the homework folder to the myfolder folder.

  2. Some major benefits of using R Projects are that they keep all files for a project organized in one location, which make relative file paths easier to use and provide a consistent working directory. This also makes it easier to use Git and GitHub for a project.

  3. Git is a version control system that tracks changes made to files and allows users to keep different versions of their work. GitHub is an online platform that hosts Git repositories and makes it easy to store, share, and collaborate on projects.

  4. Two main differences between a tibble and a data.frame are:

    • Tibbles print only the rows and columns that fit on the screen instead of the entire data set
    • Tibbles are more strict about how they handle variables and do not automatically change things such as variable names or data types in the way traditional data frames might

Task 4: Writing a Function

Question 8

I created the getIQR() function to calculate the interquartile range by subtracting the 25th percentile from the 75th percentile. I used unname() so the returned value does not have a percentile name.

getIQR <- function(x, ...) {
  quartiles <- quantile(x, probs = c(0.25, 0.75), ...)
  unname(quartiles[2] - quartiles[1])
}

Question 10

I created getCoefVar() to calculate the sample coefficient of variation by dividing the sample standard deviation by the absolute value of the sample mean.

getCoefVar <- function(x, ...) {
  sd(x, ...) / abs(mean(x, ...))
}

I created the wrapper function getSummaries() to return both the IQR and coefficient of variation. Instead of repeating the calculations, the function calls the two functions created above.

getSummaries <- function(x, ...) {
  c(
    IQR = getIQR(x, ...),
    CoefVar = getCoefVar(x, ...)
  )
}
