Task 4

first we are placing the subjects in three different groups based on blood pressure, optimal is less than 121, borderline is from 121 to 130 inclusive, and high is above 130. This is done for both the treatment and the placebo groups.

bp_list$treatment$status= character(20)
bp_list$placebo$status= character(10)
#nrow just gets the number of rows, easier than remembering how many rows it has

for (i in 1:nrow(bp_list$treatment)) {
  if (bp_list$treatment$post_bp[i] <= 120) {
    bp_list$treatment$status[i] <- "optimal"
  } else if (bp_list$treatment$post_bp[i] <= 130) {
    bp_list$treatment$status[i] <- "borderline"
  } else {
    bp_list$treatment$status[i] <- "high"
  }
}
