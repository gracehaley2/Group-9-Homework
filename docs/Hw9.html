Introduction

This assignment looks at how weather, season, holidays, and day type relate to daily bike rentals in Seoul. We first performed early data exploration and cleaned the data, then aggregated it into daily observations. Then, we compared three multiple linear regression models!

The data set is from https://www4.stat.ncsu.edu/~online/datasets/SeoulBikeData.csv.

Clean dates, factors, and column names

Dates are recorded here in day/month/year order, so we use dmy(). We convert the categorical variables into factors and rename the columns to make them easier to use.

bikes <- bikes |>
  rename(
    date = Date,
    bike_count = `Rented Bike Count`,
    hour = Hour,
    temp = `Temperature(°C)`,
    humidity = `Humidity(%)`,
    wind_speed = `Wind speed (m/s)`,
    visibility = `Visibility (10m)`,
    dew_point = `Dew point temperature(°C)`,
    solar_radiation = `Solar Radiation (MJ/m2)`,
    rainfall = `Rainfall(mm)`,
    snowfall = `Snowfall (cm)`,
    seasons = Seasons,
    holiday = Holiday,
    functioning_day = `Functioning Day`
  ) |>
  mutate(
    date = dmy(date),
    seasons = factor(
      seasons,
      levels = c("Winter", "Spring", "Summer", "Autumn")
    ),
    holiday = factor(
      holiday,
      levels = c("No Holiday", "Holiday")
    ),
    functioning_day = factor(functioning_day)
  )

Standardize the weather predictors

For each weather predictor, we subtract its training mean and divide by its training standard deviation.

The test data must use the same training means and standard deviations, which prevents test set information from influencing preprocessing.

We keep the original variables and create standardized versions with the ending _z. We don’t need to standardize the rental count.

  "temp", "humidity", "wind_speed", "visibility",
  "dew_point", "solar_radiation", "rainfall", "snowfall"
)

training_means <- sapply(train[weather_vars], mean)
training_sds <- sapply(train[weather_vars], sd)
