Introduction

This assignment continues our analysis of daily bike rentals in Seoul. We reuse the data reading and EDA from Homework 9, then use tidymodels to compare three multiple linear regression specifications, a regression tree, bagged trees, and a random forest. We select model configurations with 10-fold cross-validation, compare the selected models on test RMSE and MAE, and refit the overall winner on all daily observations.

The data set is from https://www4.stat.ncsu.edu/~online/datasets/SeoulBikeData.csv.

Clean dates, factors, and column names

Dates are recorded here in day/month/year order, so we use dmy(). We convert the categorical variables into factors and rename the columns to make them easier to use.

bikes <- bikes |>
  rename(
    date = Date,
    bike_count = `Rented Bike Count`,
    hour = Hour,
    temp = `Temperature(°C)`,
    humidity = `Humidity(%)`,
    wind_speed = `Wind speed (m/s)`,
    visibility = `Visibility (10m)`,
    dew_point = `Dew point temperature(°C)`,
    solar_radiation = `Solar Radiation (MJ/m2)`,
    rainfall = `Rainfall(mm)`,
    snowfall = `Snowfall (cm)`,
    seasons = Seasons,
    holiday = Holiday,
    functioning_day = `Functioning Day`
  ) |>
  mutate(
    date = dmy(date),
    seasons = factor(
      seasons,
      levels = c("Winter", "Spring", "Summer", "Autumn")
    ),
    holiday = factor(
      holiday,
      levels = c("No Holiday", "Holiday")
    ),
    functioning_day = factor(functioning_day)
  )

Recipe 1: Main effects

We extract the day of the week and convert it into a weekday/weekend factor. With numeric output from step_date(), Sunday is 1 and Saturday is 7. We remove the original date and intermediate day-of-week variable, standardize the eight numeric weather predictors, and then create dummy variables for the categorical predictors.

recipe1 <- recipe(bike_count ~ ., data = train) |>
  step_date(date, features = "dow", label = FALSE) |>
  step_mutate(
    day_type = factor(
      if_else(date_dow %in% c(1, 7), "Weekend", "Weekday"),
      levels = c("Weekday", "Weekend")

  ) |>

  step_normalize(all_numeric_predictors()) |>
