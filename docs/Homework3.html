  1. This is my IQR function which which you can pass unnamed arguments to. IQR is 75th percentile minus 25th percentile.
getIQR <- function(x, ...) {
  q <- quantile(x, probs = c(0.25, 0.75), ...)
  # This line removes the labels on the returned vector result.
  unname(q[2] - q[1])
}

  1. This is my getCoefVar function which you can pass unnamed arguments to. Coefficient of variation is standard deviation divided by the absolute value of mean.
getCoefVar <- function(x, ...) {
  sd(x, ...) / abs(mean(x, ...))
}
  1. This code runs the getCoefVar function twice on the specified columns from my wine object and displays the results.

  1. Here, I’m creating a function called getSummaries which calls both the IQR and CoefVar functions. There’s no need to rewrite them since we can just call them within this function.
getSummaries <- function(x, ...) {
  # Have to make sure to label them to not get confused.
  c(
    IQR = getIQR(x, ...),
    CoefVar = getCoefVar(x, ...)
  )
}
